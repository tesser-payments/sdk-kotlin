# `:sdk-ktor` (Reserved for Phase B)

This module is intentionally empty in v0.0.1. It is reserved for the Ktor adapter
described in the design spec (§7.7) — a `KtorHttpTransport` class that lets
Ktor-using applications share their existing `HttpClient` with the Tesser SDK.

Phase B implementation has not started. Do not depend on this module yet.
